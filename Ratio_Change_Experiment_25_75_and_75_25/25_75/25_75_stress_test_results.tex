\begin{center}
{\Large \textbf{25/75 YES/NO Stress Test Results on POPE Benchmark}}\\[4pt]
{\large Ground truth label ratio: 25\% YES / 75\% NO}\\[2pt]
{\normalsize Baseline is the reference point for FN$\to$TP and TN$\to$FP columns.}
\end{center}

\vspace{6pt}
\noindent\textbf{Column definitions:}
\begin{itemize}
  \item \textbf{FN$\to$TP}: Change in correctly answered YES questions relative to baseline (positive = more correct YES answers recovered).
  \item \textbf{TN$\to$FP}: Change in incorrectly answered YES questions relative to baseline (positive = more wrong YES answers introduced).
  \item \textbf{Yes\%}: Proportion of questions answered ``yes'' by the model.
  \item \textbf{Acc\%}: Overall accuracy on the 25/75 filtered benchmark.
\end{itemize}
\noindent\textbf{Note:} Each image retains 1 YES and 3 NO questions (2000 total per split).
The same YES question ordinals are deleted consistently across all POPE variants
(Random, Popular, Adversarial) and all decoding methods for each image (seed = 42).
\textbf{CD methods:} VCD, SID, ICD. \textbf{Spurious baselines:} PBA (prompt: ``Answer yes whenever possible.''), OLM (output label manipulation).
