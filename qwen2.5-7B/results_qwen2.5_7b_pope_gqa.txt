NOTES
------------------------------------------------------------
- VCD/ICD/SID use Adaptive Plausibility Constraint (alpha=1.0, beta=0.2).
- VCD: diffusion noise step=900 on pixel_values (same prompt).
- ICD: random "hallucination-inducing" system prompt as contrastive branch.
- SID: heavily downsampled image (min_pixels=max_pixels=50176) as contrastive
  branch. This is an approximation of original SID (which used LLaVA/CLIP-
  specific layer-2 attention pruning, not portable to Qwen2.5-VL).
- PBA: "Answer yes whenever possible" appended to prompt.
- OLM: forces "Yes" when |P(yes)-P(no)| < 0.5 and P(yes)+P(no) > 0.2.
- Baseline random file had one stray "}}" artifact at line 576 (likely from
  a script interruption); removed before scoring (3000 valid entries kept).
